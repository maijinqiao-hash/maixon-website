01

产品概览

4大生产工艺：DTF / DTG / 热升华 / 半色调
7个 AI 工具：提取、抠图、变清晰、改图、扩图、裁切、转矢量
8种界面语言，切换后布局与输入不丢
2种 RIP 直连：蒙泰 MainTop、FlexiPrint / PP

02

安装与首次启动

第一次使用，按“安装 → 登录 → 引导 → 连 PS → 设导出目录”的顺序走一遍，后面能省很多事。

2.1 安装

1运行安装包Win10/11 x64 环境，按向导下一步。
2选择安装位置默认路径即可。本版已支持长路径，但第三方脚本/插件未必兼容，目录别设得太深。
3完成安装桌面出现 MAIXON TOOL 快捷方式，启动后进入登录。

2.2 登录账户

软件用邮箱验证码登录。授权跟着账户走：登录后，哪些模块可用、什么时候到期，会自动显示在“我的账户”和侧栏底部。

1输入邮箱填写常用邮箱，勾选用户协议。
2获取验证码点“获取验证码”，去邮箱查收 6 位数字。
3登录填入验证码，点“登录 / 创建账户”。
4授权自动生效已购买的模块直接可用，无需额外操作。
新邮箱会自动创建账户。第一次登录没有授权是正常的——购买或续费后，授权会开通到这个邮箱账户，重新登录或点一下刷新即可。

2.3 首次启动引导

第一次打开会出现三步引导：欢迎（了解能做什么）→ 账户（登录或稍后）→ 工具（选择常用工艺）。引导可以随时从“使用说明 → 重新打开功能指南”再次打开。

2.4 启动后的第一件事

  1. 看底部状态栏：授权是否可用、Photoshop 是否已连接。
  2. 打开“设置 → 导出位置”，把单图制图、单图排版、多图排版、指定画布、白墨直喷、PDF 热升华、PSD/PSB 裁片七个工艺的导出目录分别设好。
  3. 如果要用 PS 相关功能，点“启动 / 连接 Photoshop”，确认能读到当前图稿。

04

生产概览

这是每天开工的第一个页面：五个大卡片对应五种生产路径，下面还有一个“图稿准备”入口。

DTF白墨烫画

单图制图 / 单图排版 / 多图排版。输出 CMYK + W1 烫画膜 TIFF。

DTG白墨直喷

深色 / 浅色面料白墨控制，去黑、抠白，可先白墨预览再套位。

SUB热升华数码

PDF / PSD / PSB 裁片，纯矢量排版，布纹安全 0°/180°。

AIAI 工作台

提取 · 增强 · 抠图 · 改图 · 扩图 · 裁切 · 转矢量，云端算力按积分计。

下方“图稿准备 → Photoshop 本地抠图”是一个独立小工具：调用 PS 把不透明背景处理成透明图，保留原图层，并单独生成“MAIXON_抠图结果_请检查”图层，方便你放大核对边缘。

自动抠图不是 100% 准确。复杂背景、毛发、半透明边缘和近似色都可能漏抠或误抠。务必放大检查后再跑 DTF / DTG / 排版，否则白墨和切割都会跟着错。

05

白墨烫画 DTF

DTF 是这套软件的主战场：把任意图稿变成“CMYK 彩墨 + W1 白墨”的烫画膜生产文件。四个标签页对应四种接单方式，输出格式统一为 CMYK + W1 的 TIFF。

FIG.03 · DTF 四个入口，各自负责什么

5.1 单图制图：一张图做一张膜

适合“客户只给一张图，要一张成品”。流程是：选图 → 看白墨 → 定尺寸 → 导出。

  1. 给图。点“选择图稿”选文件，或点“读取 Photoshop 当前图稿”直接抓 PS 当前文档/图层。
  2. 看预览。“彩色预览”看图案本身；“白墨预览”看 W1 通道会铺在哪里，这一步能提前发现白墨盖字、边缘露白。
  3. 定尺寸。打开“指定尺寸”可填目标宽度；“切割框”开关决定是否同时生成切割轮廓（默认关闭）。
  4. 调参数。展开“更多设置”，按面料和 RIP 调整分辨率、W1 收缩、每边扩边、LZW、ICC。
  5. 导出。点“制图并导出 TIFF”，完成前可随时“停止加载”。

5.2 单图排版：同一张图铺满整卷

这个页面是两步式设计，刻意把“排版”和“加白墨”分开：

1排版旋转、裁边、改尺寸、扩边，按目标模式排成一行或多行；此步不建 W1。
2出白墨选通道模板，生成 W1 专色通道并导出生产 TIFF。

左右滑动查看完整表格

排版目标怎么算
普通排版按最大排版宽度铺一整行，能放几张放几张。
米数排版填“目标米数”，换算成需要的高度，再决定行数。
面积排版填“目标面积”，按换算高度生成，适合按平方米报价的订单。

软件里的算例：扩边后单图宽 16 cm、最大宽度 57 cm → 一排 3 张，每格 19 cm，总宽 57 cm。

排版稿的外边距锁定为 0。整版最外侧不会再扩边，最终宽度始终等于你设置的卷材宽度。这是为了 RIP 拼版时不被二次缩放。

5.3 多图排版：一单多图拼整版

  • 最大排版宽度：通常就是卷材宽度（示例 57 cm）。
  • 文件名识别尺寸/数量：文件名里带尺寸或数量的，可直接读出来参与排版，减少手填。
  • 允许旋转：只旋转“确实能省料”的图，不是全部乱转。
  • 轮廓穿插：按透明外轮廓嵌套，三角形、异形图更省膜。
  • 最终整图扩边：锁定 0 cm，保证整版宽度不变。
订单文件夹怎么建：一个订单一个文件夹，图稿直接放根目录，文件名用“客户-图名-尺寸”。软件会跳过无法识别的文件并在日志里说明，不会静默漏图。

5.4 指定画布：先统一最长边，再拼版

左右滑动查看完整表格

参数说明
目标最长边统一后每张图的最长边长度（示例 25 cm）
最大排版宽度整版宽度（示例 57 cm）
图与图净间距图之间的空隙（示例 0.3 cm），不含白墨扩边
允许旋转 / 轮廓穿插与多图排版一致，按需开启
中间输出格式 / 文件名编码在“更多设置”里，决定预处理产物格式与命名标签

它和“多图排版”的区别：多图排版保留每张图原尺寸；指定画布会先把尺寸不一的图统一到同一最长边，再排版，适合“客户图大小乱七八糟、但成品要一样大”的场景。

5.5 切割框（Cut Line）

  • 四个 DTF 流程各自有独立开关，默认关闭，互不影响。
  • 切割线基于 Fabric Piece 的外轮廓向外生成，不覆盖印花、文字或 Logo。
  • 输出为黑色 Cut Line，方便烫画机/切割机识别。
  • 开关在预览区右上角，切换后预览会立即反映。

压缩LZW 或 无压缩，两种都保留 CMYK 与 W1
兼容蒙泰、NeoStampa 等 RIP 可直接读取

白墨直喷 DTG

DTG 和 DTF 共用“白墨通道”思路，但控制重点不同：DTF 关心膜上的白墨层，DTG 关心面料颜色——深色布要多铺白，浅色布要少铺甚至抠白。

6.1 面料颜色

软件内置一排面料色卡：深色、浅色、粉色、蓝色、黄色、绿色、灰色、红色、青色、紫色。也可以“自选颜色”，或“从图稿取色”直接吸图案里的颜色。

选颜色不是装饰——它决定“面料相近区域”的白墨量。示例：面料相近区域白墨 5%，其它图案白墨 50%，意思是贴着布料底色的地方只补很少白墨，图案主体正常铺 50%。

6.2 白墨密度怎么设

左右滑动查看完整表格

面料策略典型值
深色 / 黑色普通图案区域铺白；CMYK 的 K 黑色区域只铺 0–10% 白墨，避免黑上叠白发灰、发硬普通 50%，K 区 0–10%
浅色 / 白色整体白墨密度；可勾“抠白”，纯白图案区域不喷白墨整体 30–50%
浅蓝、浅粉等有色浅布通常取消“抠白”，否则图案里的白会和布色打架按打样微调
原通道不动。DTG 只新增/修改专色通道，CMYK 四个原始通道不会被改写；专色通道名称可改，默认 W1。

6.3 操作顺序

1加图“添加图稿”或“导入文件夹”，也可读取 PS 当前图稿。
2选面料点色卡或取色，确认深/浅色策略。
3调白墨面料相近区域、其它图案两档密度。
4预览彩图 / 白墨切换，检查有没有该白不白、不该白乱白。
5出图“生成白墨图稿”，再“保存图稿”或“进入套位”。
“进入套位”是什么：把当前白墨图稿带到 DTG 套位页，按实际印花位置摆放，适合成衣定位打印；只做平面图稿时用“保存图稿”即可。

6.4 DTG 套位

“DTG 套位”标签用来把印花摆到成衣的实际位置，适合成衣定位打印。它不改白墨，只改位置和尺寸。

  • 设台板与印花尺寸：先填台板尺寸和印花尺寸，软件按毫米计算可放置区域。
  • 拖动定位：鼠标拖动改变位置；方向键微调 0.1 mm，Shift + 方向键 1 mm，Alt 可自由拖动。
  • 快速对齐：左对齐、右对齐、顶部对齐、底部对齐、水平居中、上下居中，还有偏上/偏下定位。
  • 边界检查：印花大于台板、或图案超出台板时会提示，必须调整后才能真正导出，避免打偏。
  • 导出：位置确认后导出套位结果，进入 RIP 或打印流程。
先打小样再批量。不同面料、不同预处理液、不同 RIP 的白墨表现差异很大。深色布白墨不足会透布，过量会开裂；浅色布抠白过头会露底。建议每换一批布先打一片 10×10 cm 小样。

半色调处理

半色调把照片/渐变图转成“网点图”，用于丝印、烫画等需要网点表现的工艺。它不改变图的内容，只改变“怎么用点组成图”。

  • 30 LPI 左右：点径明显、复古/丝印感强，适合远看的大图案。

热升华排版

热升华的难点是“裁片多、形状怪、还要保持布纹方向”。MAIXON 的做法是先做纯矢量排版，确认后再导出；默认只允许 0°/180°，不破坏布纹。

8.1 PDF 矢量排版

  1. 选文件。拖入或选择透明背景 PDF（也支持 AI）。软件读取 PDF 内的 Form XObject，不栅格化。
  2. 填参数。卷材宽度（示例 1620 mm）、裁片净间距（示例 3.0 mm）、是否要裁切线。
  3. 选方案。点“生成三种方案”，快速方案先返回，均衡与最省料随后生成。
  4. 看预览。在预览里检查重叠、方向、留白；已完成的方案会冻结，不会被后续计算改掉。
  5. 导出。推荐“打开 PDF”走矢量；需要 PS 加工时用“Photoshop TIFF”；EPS 为实验功能。

8.2 三种方案的区别

  • 输入是“一个文件夹”，里面放本单所有 PSD/PSB 裁片；勾选“输入兼容”可包含 PSB 大文件。

典型工作流

下面三条路线覆盖了 80% 的日常订单。第一次用建议照着走一遍，把每个环节的目录和参数固定下来。

路线 A：一张图 → DTF 成品膜

1连 PS打开 Photoshop，软件状态栏显示已连接。
2进单图制图生产概览 → 白墨烫画 → 单图制图。
3读图读取 PS 当前图稿，或选择图稿文件。
4看白墨切到“白墨预览”，确认没有盖住文字/细线。
5定尺寸开“指定尺寸”，填成品宽度；需要切割就开切割框。
6设参数300 PPI、W1 收缩 2 px、每边扩边 5 mm。
7导出制图并导出 TIFF，确认文件名与保存位置。

导出后如果开了“自动进入 RIP”，文件会直接进蒙泰/PP；否则点顶栏“TIFF → RIP”手动发送。

01
选择图稿从文件选择，或读取 Photoshop 当前图稿

路线 B：整单多图 → 整版 → RIP

  1. 整理订单文件夹：一个订单一个文件夹，图稿放根目录；文件名写“客户-图名-尺寸”，需要读尺寸/数量时打开对应开关。
  2. 进多图排版：选择图片文件夹，设最大排版宽度（=卷材宽度，如 57 cm）。
  3. 按需开两个开关：允许旋转（只转省料的图）、轮廓穿插（异形图省膜）。
  4. 排版并导出 TIFF：等待处理完成，检查整版预览有没有重叠、方向错、漏图。
  5. 核对完成提示：看单图宽度、排数、总宽、总高是否符合预期，再点“打开文件夹”。
  6. 送 RIP：手动或自动进入 RIP，选预设并开始。
“完成”不等于“导出了”。排版完成只是版面算好了；必须再执行“生成 W1 并导出 TIFF”，否则 RIP 里拿不到带白墨的文件。

路线 C：热升华 PDF → 矢量排版 PDF

  1. 检查源文件：PDF 需透明背景，裁片是独立对象；如果是 PSD/PSB，走“PSD / PSB 裁片”标签。
  2. 进 PDF 热升华排版：拖入 PDF/AI，设卷材宽度与裁片净间距。
  3. 生成三种方案：快速先出，均衡/最省料随后；赶单直接看快速，材料贵就等最省料。
  4. 预览检查：重点看裁片有没有重叠、旋转是否保持布纹方向、边缘是否超出卷宽。
  5. 导出：优先“打开最终矢量 PDF”；需要 PS 加工选 Photoshop TIFF；EPS 仅实验。
  6. 分卷核对：超过单卷最大高度会自动拆成多个 PDF，逐个检查序号与内容。
